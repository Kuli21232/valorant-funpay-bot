# Valorant FunPay Bot

Бот для автоматизации аренды Valorant-аккаунтов через FunPay с админ-панелью в Telegram.

## Быстрая установка (Windows)

1. Установите **Python 3.12** (рекомендуется): https://www.python.org/downloads/release/python-3127/
   - Подходят также 3.11 и 3.13.
   - **НЕ** ставьте Python 3.14 — он слишком новый, многие библиотеки ещё не имеют под него готовых сборок под Windows.
   - При установке обязательно поставьте галочку **Add Python to PATH**.
2. Распакуйте архив с ботом в любую папку.
3. Двойной клик на **`install.bat`** — установщик всё сделает сам:
   - создаст виртуальное окружение
   - установит зависимости
   - скачает браузер для Playwright
   - запустит мастер настройки `.env`
   - создаст базу данных
4. После установки запустите **`run.bat`**.

## Что нужно подготовить заранее

| Параметр | Где взять |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Напишите [@BotFather](https://t.me/BotFather) → `/newbot` |
| `TELEGRAM_ADMIN_ID` | Напишите [@userinfobot](https://t.me/userinfobot) |
| `FUNPAY_GOLDEN_KEY` | Браузер → F12 → Application → Cookies → `funpay.com` → `golden_key` |
| `FUNPAY_PHPSESSID` | Там же, cookie `PHPSESSID` |
| `FUNPAY_USER_ID` | Цифры из URL `https://funpay.com/users/XXXXXX/` (ваш профиль) |

## Управление аккаунтами

Запустите **`add_account.bat`** для добавления / просмотра / удаления Valorant-аккаунтов в базе.

## Запуск

- **`run.bat`** — старт бота
- **`add_account.bat`** — управление Valorant-аккаунтами
- В Telegram отправьте боту `/start` — появится админ-меню

## Структура меню Telegram

```
/start
├── Все аккаунты
│   └── [Account#TAG (свободен/занят)]
│       ├── Кик пользователя       — завершает сессию в Riot
│       ├── Статус занятости       — показывает текущий статус
│       └── Чек ранга              — показывает сохранённый ранг
└── Завершить все сессии          — глобальный кик по всем аккам
```

## Обновление PHPSESSID

Cookie `PHPSESSID` истекает раз в ~40-60 минут. Когда это произойдёт, бот пришлёт уведомление в Telegram. Откройте `.env`, обновите значение и перезапустите бота (`run.bat`).
